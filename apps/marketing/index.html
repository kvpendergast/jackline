Brand mark — reset

Stop illustrating. Start identifying.

The name already says jackline. A principal designer would not draw pad eyes and a carabiner into a 16px favicon. They’d ship a clear letter, let the product story live in copy and UI, and keep metaphor as a whisper — not a diagram.

What changed in the brief

  • One idea. A J. Not a J + rope + clip + anchors.
  • 16px first. If it fails as a favicon, it fails.
  • Metaphor is optional. The wordmark carries the meaning; the mark carries recognition.
  • Wordmark can lead. Many strong products (Linear, Stripe early days) ship name first.

Default pick

Solid J

Filled geometric letter. Confident at every size. Same class as Notion / Linear monograms.

Quiet

Monoline J

One stroke. Feels slightly more “line / tether” without becoming a sailing diagram.

App icon

Tile

Solid J on a rounded square. For OS dock, Slack app, mobile — not for page headers.

Often best

Wordmark only

No icon. Just a tuned “Jackline.” Honest for a young product; icon can come later.

How it works

Three moves. Same as on deck.

A jackline is the rope you clip to before crossing the deck. Jackline the product works the same way for AI tools.

01

Clip in

Register your agent (Cursor, Claude Code, internal bots). Mint a connection token — that's your carabiner to Jackline.

02

Explore

Agents call MCP tools through Jackline. Upstreams like Linear, GitHub, and Gmail sit behind one gateway you own.

03

Stay safe

Roles, approvals, and audit logs catch what shouldn't happen. Deny by default — grant only what each builder needs.

Two light-mode moods — toggle above
