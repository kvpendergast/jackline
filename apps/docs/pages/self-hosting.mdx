# Self-hosting

## Production (recommended)

Multi-stage images + Caddy edge proxy:

```bash
cp deploy/.env.prod.example .env.prod
# set MESH_MASTER_KEY and BETTER_AUTH_SECRET (openssl rand -base64 32)

docker compose -f deploy/compose.prod.yml --env-file .env.prod up --build -d
```

| URL | Service |
| --- | --- |
| http://localhost/ | Admin UI (`/api`, `/mcp` on the same origin) |
| http://docs.localhost/ | Docs |
| http://localhost/openapi.json | OpenAPI JSON |
| http://localhost/health | API health |

Set `MESH_HOST`, `WEB_ORIGIN`, `BETTER_AUTH_URL`, and `MESH_PUBLIC_*` when using a real domain.

## Dev Compose

Hot-reload stack (`tsx` / Vite):

```bash
cp .env.example .env
docker compose -f deploy/docker-compose.yml up --build
```

| Service | Port |
| --- | --- |
| Postgres | 5433 → 5432 |
| API | 8080 |
| Gateway | 8081 |
| Admin UI | 5173 |
| Docs | 3000 |

## Local development (no Docker)

```bash
pnpm install
cp .env.example .env
pnpm db:migrate
pnpm dev          # api + web + gateway
pnpm docs:dev     # Zudoku on :3000 (exports OpenAPI first)
```

## Regenerating the API reference

```bash
pnpm openapi:export   # writes apps/docs/apis/openapi.json
pnpm docs:dev         # or docs:build
```

`docs:dev` runs the export automatically via `predev`. Commit an updated `openapi.json` before building production docs images.
