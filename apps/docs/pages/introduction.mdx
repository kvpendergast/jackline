# Jackline

The open-source MCP control plane. Clip in, then go build.

Jackline is a self-hostable **MCP policy gateway** with a control-plane API and admin UI.

Clients (Cursor, Claude Code, agents) connect to Jackline as an MCP server. Jackline authenticates the caller, evaluates policy, proxies allowed tool calls, and records an audit trail.

## What's in these docs

- **Guides** — Docker self-host, connect Cursor, [harness re-auth](/harness-reauth), Admin API auth, [A2A agents MVP](/a2a-agents)
- **[API Reference](/api)** — generated from OpenAPI (`GET /docs` on the API)

## Quick start (generic Docker)

```bash
cp .env.example .env
# set POSTGRES_PASSWORD, JACKLINE_MASTER_KEY, BETTER_AUTH_SECRET
#   openssl rand -base64 32

pnpm env:check   # optional
docker compose -f deploy/docker-compose.yml up --build
```

| Surface | Default URL |
| --- | --- |
| Admin UI | http://127.0.0.1:5173 |
| API | http://127.0.0.1:8080 |
| Gateway MCP | http://127.0.0.1:8081/mcp |
| Docs (this site) | http://127.0.0.1:3000 |

Then [connect Cursor](/connect-cursor). For production images, Postgres overlay, GCP, and edge recipes, see [Self-hosting](/self-hosting).

## Local development (no Docker)

```bash
pnpm install
cp .env.example .env
pnpm env:check
pnpm db:migrate
pnpm dev
```

OpenAPI JSON from a running API: [`GET /docs`](http://127.0.0.1:8080/docs).
